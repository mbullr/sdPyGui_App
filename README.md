# sdPyGui_App
Sample Gui app using FreeSimpleGUI with sd

This is a work in progress, its main intent is to test FreeSimpleGUI and sd iteration. So do not expect a polished app! 

steps to use:

Download this repo.

Create PYGUI and PYGUI_INCLUDES as directory files within your sd account.

Copy the files (items) from the download into the associated sd files

Compile the programs in PYGUI

Run BLD_CM to create the demo database

Run CM.BP to see the demo app (FreeSimpleGUI and Tkinter must be installed!)
